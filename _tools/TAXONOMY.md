# 分类与标签约定

> 建站初期的骨架（2026-09-30 定），以后写新文章照着填，站内目录才不会乱。
> 规范：**分类 = 少而稳定**（3~5 个就好，尽量挂已有分类）；**标签 = 多而自由**（3~6 个，按主题随手加）。

## 分类（categories）

分类在 Hexo 里天然按层级排，`categories` **每写一行就是一层**。站点就 3 个大类，长期别扩：

| 分类 | 用途 | 已用子分类 |
| --- | --- | --- |
| 技术折腾 | 代码、工具、本站搭建与踩坑 | 博客搭建 |
| 成长手记 | 学习心得、阶段复盘、心路历程 | — |
| 生活随笔 | 日常记录、随想、杂谈 | — |

写新文章的 front-matter 时，一行一个层级：

```yaml
categories:
  - 技术折腾            # 只挂大类
```

```yaml
categories:
  - 技术折腾
  - 博客搭建            # 挂到大类下的子分类（会同时出现在两个分类页里）
```

顺序由 `_config.yml` 的 `category_map` 控制。

## 标签（tags）

扁平、不设层级，随便加。目前已有：

`博客`、`博客搭建`、`hexo`、`开篇`、`心路历程`

新文章建议再按需取用这些方向：`NexT`、`GitHub Pages`、`前端`、`搜索`、`Live2D`、`音乐`、`友链`、`学习笔记`、`数据科学`、`复盘`、`和风`、`Miku`……

## 新建文章模板

```bash
npx hexo new "文章标题"
```

然后手动把 front-matter 补成这样：

```yaml
---
title: 文章标题
date: 2026-09-30 20:00:00
categories:
  - 成长手记
tags:
  - 学习笔记
  - 复盘
---
```

## 维护提醒

- 现有的 3 个分类 + 5 个标签是骨架，**不要为了一篇文章单开一个新大类**。
- 标签页的标签云在 NexT 里按数量排大小，标签多了自然好看，别急着凑数。
- 分类页 / 标签页的入口在顶部菜单：`/categories/`、`/tags/`，内容由 Hexo 自动生成，不用手写。
